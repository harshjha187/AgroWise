About AgroWise

AgroWise is an IoT-based Smart Soil Health Analysis, Barren Land Detection and Automated Recovery Recommendation System.

Sensors (NPK, soil moisture, pH and temperature) feed raw packets into a Flask + SQLite backend, which runs a validate → filter (EMA noise reduction) → score → classify → recommend pipeline and stores every analyzed reading and alert.

This dashboard and the AgroWise Field mobile app both talk to the same REST API, so any device — ESP32 firmware, the built-in simulator, or a manual entry from either app — updates every connected client in real time.
